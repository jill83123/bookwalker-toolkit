# BookWalker 小工具

統計 [BookWalker 台灣](https://www.bookwalker.com.tw/) 的購書花費、本數與折數，並在購物車用「原價」試算實際折數、比較各活動。

> 非官方工具，與 BOOK☆WALKER 無關。資料只存在你的瀏覽器，不會上傳到任何伺服器。

## 功能

- **消費統計**：依年份查看總花費、月均消費、最高單月、訂單數、本數與折數；每月／每年趨勢圖；月明細、訂單明細（可展開每本書的原價與本數）、年度總計。
- **購物車試算**：結帳頁沒有原價，這裡用原價算出實際折數；可填優惠券、點數、會員等級、滿額活動，比較各活動的結帳金額與實際花費。
- **備份**：手動匯出／匯入 JSON。

## 安裝

1. 開啟 Chrome，進入 `chrome://extensions/`。
2. 開啟右上角「開發者模式」。
3. 按「載入未封裝項目」，選擇這個資料夾（含 `manifest.json` 的那一層）。

之後修改檔案，只要在 `chrome://extensions/` 按該擴充功能的「重新載入」即可，不用重裝。

> **搬移或重新載入到不同資料夾時**，Chrome 會把它當成新的安裝，原本的訂單資料會消失。請先到「備份」頁匯出 JSON。

## 使用

### 掃描訂單

需先在 Chrome 登入 BookWalker。到統計頁的「消費」分頁，或按工具列圖示：

- **掃描全部**：抓取所有「付款完成」的訂單與每筆明細（書名、類別、原價、本數）。舊資料沒有明細時，再按一次會補抓。
- **只掃新訂單**：從最新一頁開始，遇到已存在的訂單就停止，通常幾秒完成。

掃描在背景進行，不會開分頁；請求之間會有間隔，避免短時間大量請求。

### 計算方式

- 共買幾本 = 所有項目本數加總。
- 訂單折數 = 結帳金額 ÷ 明細原價總和（已含折價券與點數折抵）。
- 「納入免費書籍」預設關閉：關閉時排除 $0 的項目與結帳金額 $0 的訂單，影響本數、訂單數與折數。

### 購物車試算

加入書的方式有兩種：

- 統計頁按「讀取購物車」：讀取購物車的書單與售價，原價由各商品頁取得。
- 在商品頁按「加入購物車試算」；也可以「手動新增」原價與售價。

勾選要算的書，右側可填優惠券折抵、點數折抵、會員等級（點數回饋率）、滿額送／滿額再折（自訂活動）。活動比較表中的常見活動只是範例規則，**僅供參考，以官網當期活動為準**；全館折扣以原價計算，且不會比目前售價更貴。把結帳頁的金額填進「實際結帳金額」，可算出這車的真實折數。

### 備份

統計頁「備份」分頁可匯出／匯入 JSON（含全部訂單與設定）。匯入會覆蓋目前訂單資料。

## 權限與隱私

| 權限 | 用途 |
|---|---|
| `storage` | 把訂單與設定存在本機 |
| `offscreen` | 在背景解析 BookWalker 的 HTML（service worker 沒有 DOMParser） |
| `https://member.bookwalker.com.tw/*` | 讀取訂單列表與明細 |
| `https://www.bookwalker.com.tw/*` | 讀取購物車、商品頁價格，並在商品頁顯示按鈕 |

資料只存在 `chrome.storage.local`。唯一對外的連線是頁面載入 Google Fonts 字體（Inter、Chiron Hei HK），離線時會退回系統字型。

## 專案結構

```
manifest.json        擴充功能設定（Manifest V3，含固定 ID 用的 key）
background.js        service worker：掃描流程、節流、儲存
offscreen.html/js    背景解析 HTML（訂單列表、明細、購物車、商品價格）
popup.html/js        工具列小視窗：開啟統計頁、掃描
dashboard.html/js    統計頁：消費、購物車試算、備份
cart.js              購物車試算
backup.js            匯出／匯入
components.js        下拉選單、折疊區塊元件
icons.js             Lucide 圖示（lucide-static，ISC 授權）
price-helper.js      商品頁：原價／折數與「加入購物車試算」按鈕
theme.css            共用樣式（配色取自 BookWalker 官網）
chart.min.js         Chart.js 4.4.1
icons/               擴充功能圖示
```

## 已知限制

- 依賴 BookWalker 頁面的 HTML 結構（訂單列表、明細、購物車、商品頁的價格資料）；網站改版後可能需要調整。
- 商品頁的價格是前端渲染的，原價取自頁面原始碼中的追蹤事件資料。
- 官方沒有公開訂單保存期限；建議定期匯出 JSON 留存。
